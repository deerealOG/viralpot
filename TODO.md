# ViralPot Feature Roadmap

## 1. Dashboard Enhancements
- [ ] **Trending Ticker:** A scrolling marquee showing "Trending Now" topics (e.g., #AI, #SummerVibes).
- [ ] **Streak Counter:** A visual "Daily Streak" counter to encourage daily usage.
- [ ] **Content Calendar Preview:** A mini-calendar widget showing scheduled/saved posts.

## 2. Idea Generator Upgrades
- [ ] **"Surprise Me" Button:** A button that fills the topic with a random viral niche.
- [ ] **History Sidebar:** A collapsible sidebar showing the last 5 generated ideas for quick reference.
- [ ] **Save to Calendar:** A button to "schedule" an idea (mock functionality).

## 3. Caption Generator Upgrades
- [ ] **Sentiment Analysis:** Display a badge (Positive, Neutral, Exciting) for each caption.
- [ ] **Emoji Density Control:** A slider to adjust the number of emojis (Low, Medium, High).
- [ ] **Keyword Highlighting:** Automatically bold key viral words in the output.

## 4. Profile & Gamification
- [ ] **Achievement Badges:** Visual badges for "First Post", "100 Ideas Generated", "Viral Master".
- [ ] **Level System:** "Level 1 Creator" -> "Level 5 Viral God".

## 5. Global Polish
- [ ] **Keyboard Shortcuts:** `Ctrl/Cmd + Enter` to trigger generation.
- [ ] **Confetti Effect:** Trigger confetti animation when saving an item.
- [ ] **Sound Effects:** Subtle sounds for "Generate" and "Save" (optional toggle).
